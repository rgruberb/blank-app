  1. **Engle-Granger Test** (borda/título azul-ciano `#2FA8E8`; tag "OLS + ADF on residuals"): chips Time O(n) · Space O(n) · Params 2 (α,β). Best for: "Pair screening · stable hedge ratios · long-run equilibrium". Prod: "Test both directions; use EG critical values (≈ −3.3), not plain ADF tables". Código `def engle_granger(lx, ly): X = np.c_[np.ones(len(lx)), lx]; a, b = np.linalg.lstsq(X, ly, rcond=None)[0]  # hedge ratio β; e = ly − a − b*lx  # spread; return b, adf_stat(e)`. Miniatura: duas séries (amarela/azul) "ln y" e "α + β·ln x (offset)", "stationary gap ≈ ADF −4.7". Resultado: "≈ β̂ 1.52 · ADF −4.7".
  2. **Ornstein-Uhlenbeck** (verde `#34C471`; tag "Fit mean reversion"): Time O(n) · Space O(1) · Params 3 (θ,μ,σ). Best for: "Holding-period estimates · entry/exit calibration · half-life screens". Prod: "Skip pairs with long half-lives; estimates are noisy on short samples". Código `def ou_halflife(s): phi = np.polyfit(s[:-1], s[1:], 1)[0]  # AR(1) slope φ; theta = −np.log(phi)  # mean-reversion speed; return np.log(2) / theta  # half-life in days`. Miniatura: decaimento exponencial "E[s] after a shock: e^(−θt)" com "half-life = 11.5d". Resultado: "≈ half-life 11.5d (true 10d)".
  3. **Kalman Hedge Ratio** (roxo `#9B7CFF`; tag "Dynamic β"): Time O(n) · Space O(1) · Params 2 (Q,R). Best for: "Drifting hedge ratios · live recalibration · regime shifts". Prod: "Set Q (drift) and R (spread var) from training data; monitor innovations". Código `def kalman_beta(lx, ly, q, r): th, P = np.zeros(2), np.eye(2); for x, y in zip(lx, ly): P = P + q  # state drifts (random walk); h = np.array([[1, x]]); e = y − h @ th  # innovation = spread; K = P @ h / (h @ P @ h + r)  # Kalman gain; th, P = th + K*e, P − np.outer(K, h) @ P; return th  # [intercept, β]`. Miniatura: "true β · Kalman · static OLS" (β deriva após o treino). Resultado: "≈ β RMSE 0.04 vs OLS 0.05".
  4. **Z-Score Entry Rule** (laranja `#F28C28`; tag "Fade extremes"): Time O(w) · Space O(w) · Params 3 (w,in,out). Best for: "Execution rule for mean reversion · rolling normalization". Prod: "Rolling mean/std; add a stop near |z| = 4; include costs and borrow". Código `def pair_position(z, pos, z_in=2., z_out=.5): if pos == 0: return −1 if z > z_in else 1 if z < −z_in else 0  # fade extremes; if (pos == 1 and z >= −z_out) or (pos == −1 and z <= z_out): return 0  # take profit; return pos`. Miniatura: z-score rolante com bandas tracejadas ±2 e entradas marcadas. Resultado: "≈ Sharpe 0.23 OLS · 0.46 KF".
