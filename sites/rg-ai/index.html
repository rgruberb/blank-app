LeadScout

Pesquisa de IA para prospectar, em que um modelo audita o outro.

IA auditada+200% com o Carteira360
  1. Requisito
  2. Protótipo
  3. Produção
Problema
Prospectar exige pesquisar cada empresa. Pesquisa de IA sem checagem pode afirmar o que ninguém confirmou.
O que faz
Pesquisa cada lead com a API da Anthropic, dá uma nota e escreve um parecer com provas e fontes. Integra com o CRM: funil, agenda e distribuição de leads.
Como
Afirmação sem fonte verificável fica marcada como indeterminada, visível na tela.

carteira360.app

Em produção · gestão de carteira

Carteira360

Agenda, rotas de visita e alerta de cliente que parou de operar.

+200% de produtividade3 visões: gestor, gerente, celular
  1. Requisito
  2. Protótipo
  3. Produção
Problema
Numa carteira grande, quem para de operar ou fica sem visita passa despercebido.
O que faz
Organiza agenda e rotas e avisa quando um cliente parou. O gestor vê a equipe toda; o gerente vê a própria carteira, no computador ou no celular.
Como
Regras ambíguas viraram lógica determinística: prazo de visita, o que conta como atraso, o que é cliente parado.
Situação
Em produção. Com o LeadScout, +200% de produtividade.

Como entregamos

O que mantém um app de pé depois do deploy

Validação fora do tempo

O critério de aprovação é escrito antes de ver o resultado. Modelo que não passa não vai para a tela.

Retreino diário

Só publica modelos aprovados na validação, com recuo automático se o realizado sair do previsto.

Deploy com rollback

Via GitHub, com health check antes de trocar a versão.

Acesso e SSO

Acesso por papéis, senhas com hash e login único entre os apps.

Backups e monitoramento

Servidor Linux com Cloudflare Tunnel e Access, backups diários.

QA antes de cada release

Testes de API e de interface antes de publicar.
