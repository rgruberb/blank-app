# Paletas: 2 cores base + 1 acento

Fórmula repetida em 4 reels (@niki.aroca x2, @pierredelcourr, @diego.a.does) e também em @thearseniodev (DfVlIwHISSv):

> "The first two colors set the mood. The accent gives it personality." — @niki.aroca
> "Two colors that get along, and one that doesn't. That one only goes on the button you want to get clicked." — @diego.a.does
> "You don't need more colors. You just need one color that surprises people." — @niki.aroca

## Regras destiladas

1. **Duas cores base que "se dão bem"** (mesma família de temperatura/saturação, ou neutro + cor) definem o clima. Sozinhas parecem "fine", "clean but a little cold", "corporate", "a bit forgettable".
2. **Uma cor de acento que "não combina"** — contraste de matiz e alta saturação/luminosidade em relação às bases. É ela que torna a marca memorável ("now you'd recognize it anywhere", "now people screenshot it").
3. **O acento vai só no que deve ser clicado/lembrado.** O diagrama final de Dfc-Q-0yy0W resume: duas bolinhas (cream + black) = "get along — the whole page"; uma bolinha laranja = "doesn't — the button". Nos exemplos visuais o acento aparece em: botão CTA primário, um badge, uma palavra sublinhada no headline, um ícone, um detalhe de produto. Nunca em fundos grandes.
4. **Quantidade: "a little", "a touch", "a hint", "one splash".** Na prática dos frames, o acento ocupa uma fração mínima da tela (estimativa (complemento): ~5–10% da área; o resto fica em base 1 + base 2).
5. Uma combinação 2+1 funciona em contextos além de site: identidade de marca, packaging, social (Dfa860wIQn4 mostra grids de marca e embalagem).

### Variante "sistema de marca" (@ramotion, rodada 3)

Para identidade completa (não só uma landing), os cases da Ramotion usam **1 cor de marca saturada + preto/escuro +
1–2 cores de apoio** (Source: green `#06B250` + `#0D0F0E` + laranja `#F7A21B` e ciano `#16B4F2`; Borea AI: azul
`#3D5BF5` + quase preto + laranja `#F26B3A`). É o 2+1 com uma cor de apoio a mais reservada a ilustração/ícones;
continua valendo "nunca mais de 3–4 cores de marca". Verde/vermelho de dado (preço, delta) são semânticos, não de
marca. Detalhes, tipografia e antes/depois de paleta em `branding-identity.md`.

## Padrões que se repetem nas combinações

- **Base escura + base saturada fria, acento quente/neon**: charcoal+royal blue → laranja; onyx+indigo → mint; deep charcoal+violet → lime; black+electric blue → neon green.
- **Base clara neutra + base escura, acento quente saturado**: cream+ink → burnt orange; navy+white → hot pink; obsidian+ice grey → racing red.
- **Duas bases da mesma família (monocromático), acento complementar**: raspberry+pale pink → butter yellow; seal blue+navy → crimson pink.
- **O acento pode ser luz em vez de cor chapada** (Aurora Light como brilho atrás do objeto; Sunset Peach como pôr do sol) — ver `layers-and-trust-layout.md`.
- Nos antes/depois, o reel às vezes mostra primeiro **só a base 1** (ex.: só Mandarin Orange, só Aqua Jade = site todo preto/laranja) → base 2 entra → acento por último: o acento é sempre o último toque.
- **Acento quase sempre complementar ou oposto em temperatura** às bases (azul↔laranja, violeta↔lime/mint, rosa↔amarelo, verde↔rosa/pêssego).
- Nenhum exemplo usa mais de 3 cores de marca (fora fotos/ilustração).
- **Paleta mista → 1 cor** resolve mais que ajustar cada cor (antes/depois da home imobiliária, @dailywebdesign
  DfzgxEKlx8z: coral+laranja+lilás → azul único). "Cinco cores brigando parece confuso; duas ou três parecem
  confiantes" (@gg.designhub).

## Proporção 60/30/10 (@gg.designhub, `De_FtT3k-tT`, rodada 1)

Regra de sistema do carrossel "6 Design Cheat Codes" (print `De_FtT3k-tT_1.jpg`):
- **60% dominante**: canvas neutro (branco, dark slate, cinza suave);
- **30% secundária**: cards, superfícies, subtítulos, molduras;
- **10% acento**: CTAs, estados interativos, destaques de dado.

Takeaway do post: "se o design parece poluído, o acento de 10% está cobrindo 30% da tela". A proporção é de **área**,
não de opacidade (dúvida respondida nos comentários).

**Como casa com o 2+1:** base 1 ≈ 60%, base 2 ≈ 30%, acento ≈ 10%. É o mesmo modelo com número. A estimativa
anterior desta skill (acento em ~5–10% da área, complemento) fica dentro dos 10%. **Divergência leve:** nos exemplos de
@niki.aroca/@diego.a.does o acento ocupa bem menos que 10% (só o botão); trate 10% como **teto**, não como meta.

**Como usar com o 2+1 (complemento):** a rampa é a **escala tonal das bases** (tokens `--bg`, `--surface`, `--border`,
`--text-2`, `--text-1`), não 6 cores de marca. Se a rampa traz acento no fim (Arctic Blue, Neon Pop, Ocean Teal, Rose
Blush, Sunset Fusion), ele é o "+1". Rampas monocromáticas (Violet, Aqua, Forest, Slate, Monochrome) **precisam de um
acento de fora** com matiz oposto, conforme a regra 2 da skill. Padrão que se repete: base fria (azul/teal/violeta) +
acento quente (laranja/âmbar/coral), o mesmo do catálogo acima.

## Como aplicar no código (complemento)

- Defina tokens: `--base-1`, `--base-2`, `--accent` (+ derivados de texto/borda/hover). Não crie um quarto token de marca.
- Use `--accent` apenas em: CTA primário, estado ativo/foco, 1 destaque tipográfico por seção, indicadores de dado-chave.
- Cheque contraste do texto sobre o acento (WCAG AA 4.5:1 para texto normal). Acentos neon/lime/mint pedem texto escuro; racing red/hot pink/burnt orange/electric blue normalmente aceitam texto branco.
