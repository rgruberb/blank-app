# Índice visual — desktop-app-ui

Esta skill **não tem imagens próprias**. A tabela aponta para imagens que já existem nas skills de tema e servem para
app desktop / web app. Caminhos relativos à pasta da skill (`desktop-app-ui/`), no mesmo formato do `SKILL.md`. URL, domínio e descrição completa estão no
`visual-index.md` de cada skill de origem.

**Como abrir:** cada imagem custa contexto. Escolha **1–2** pela coluna "quando abrir". As folhas de contato são grades
4×3 com 12 quadros em ordem cronológica (esquerda → direita, cima → baixo); as que terminam em `_<n>` são prints
únicos. Imagens mobile (`DXeeUP7FKGs_1`, `DSIMwtvDluO_1`) e de site/landing ficam fora: estão em `mobile-app-ui` e
`website-ui`.
