# Índice visual — website-ui

Esta skill **não tem imagens próprias**: aponta para as que já existem nas skills de tema. Caminhos relativos à pasta
da skill (`.claude/skills/website-ui/`). Só entra aqui o que é de **site, landing ou marca na web**; dashboards e telas
de app ficam nos índices de `desktop-app-ui` / `mobile-app-ui`.

Folhas de contato 4×3 (`<ID>.jpg`) têm 12 frames em ordem (esquerda → direita, cima → baixo); `<ID>_<n>.jpg` são
prints únicos, menores. **Imagens custam contexto:** abra 1–2, só para *ver* composição; os números já estão nas
references. Descrição completa de cada uma no `visual-index.md` da skill de origem.
